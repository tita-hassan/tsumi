# צומי (Tsumi) – חזון והחלטות מוצר (טיוטה 0.2, 13.11.2026)

## חזון
אפליקציה לזוגות שמחזקת את הקשר הרומנטי שנדחק הצידה בשגרה. היא נותנת לכל בן ובת זוג רעיונות למחוות מותאמות אישית כלפי הצד השני, לפי העדפות והגבלות, ולומדת את הזוג עם הזמן.

## החלטות שהתקבלו

| פלטפורמות | אנדרואיד ו-iOS |

| פרטיות | הכול חסוי. הסקרים אישיים ולא משותפים. המידע מוצפן וחשוף רק ל-AI שלומד את הזוג |
| ארכיטקטורת פרטיות | צד שרת: המידע מוצפן במנוחה ונפתח רק בזמן עיבוד, בהרשאות מוגבלות ובלי שמירה אצל ספק ה-AI |

| ניתוק זוג | כשאחד מנתק את החיבור, זה מתבטל גם אצל הצד השני. נתוני הזוג נמחקים והפרופיל האישי נשמר אצל כל אחד לחיבור מחדש |

| סינון מחוות | לפי נשים / גברים / הכול. זה סינון תוכן ולא הצהרה על העדפה מינית |

| דירוג 1 | פירושו "לא בכלל" והמחווה לא תוצע, בלי כפתור חסימה נפרד |

| תוכן אינטימי | להחלטה בהמשך, אחרי בירור מגבלות (חנויות האפליקציות, גיל, חוק) |

## זרימת המוצר
1. שני בני הזוג מתקינים ומתחברים כזוג בתוך האפליקציה.
2. כל אחד ממלא שאלון בנפרד: דירוג 1–5 של "הייתי רוצה לקבל" ו-"הייתי רוצה לתת" לכל מחווה, בתוספת הגבלות ("לא אוהב עגלות קפה", "בהריון, לא יקב"). מחווה שמתנגשת בהגבלה של הצד השני מבוטלת אוטומטית.
3. כל אחד קובע תדירות לקבל ולתת (למשל פעם ביום או 3 בחודש), ותקציב חודשי למחוות בעלות כספית. המערכת מתאימה את גודל המחווה לתדירות.
4. התראה לבן הזוג עם מחווה (קטנה עד גדולה, באקראי). אפשר להחליף מחווה, לקבוע זמן מדויק או ליצור משימת משנה (למשל "להתקשר לחנות פרחים").
5. טיזר למקבל ("מחר מחכה לך הפתעה") אחרי שהמחווה והזמן אושרו.
6. יממה אחרי המחווה נשלח סקר שביעות רצון אישי לשני הצדדים, ללא שיתוף. המערכת לומדת אילו מחוות מצליחות ומנטרלת כאלה שלא.
7. פעם בחודש בוחרים מחוות לחודש הבא, ומקבלים תזכורת.
8. תאריכים מיוחדים (יום הולדת, יום נישואים) עם תזכורת והכנה מראש.
9. שאלון "למה אתה צריך תשומי": שני הצדדים ממלאים "כמה אתם מכירים אחד את השני".

## שאלות פתוחות
- מגבלות תוכן אינטימי (חנויות, גיל, חוק).
- בחירת טכנולוגיה (קוד אחד לשתי הפלטפורמות או נייטיב).
- בחירת ספק AI והסכם אי-שמירת מידע.
